# 需求文档索引

本目录存放**整个低空综合保障系统**的需求与功能分解资料。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `低空综合保障设备-软件及管理平台需求说明书-整合版.docx` | 总需求说明书（整合版），各功能模块章节号与思维导图对应 |
| `系统功能分解思维导图.html` | 三大系统 → 功能模块 → 子功能点，三层可折叠交互式导图；浏览器直接打开 |

## 系统划分（对齐思维导图）

| 思维导图 | 本仓库位置 |
| --- | --- |
| **一、设备端嵌入式软件（节点层）** | `device/groundstation/` |

## 初版边界（摘自思维导图）

- 不做飞行控制；
- 智能输出 = **建议 + 人工确认**，不自动执行；
- 雷达 / 频谱侦测 / 光电红外等为**二期预留**（插件化，可插拔）。
