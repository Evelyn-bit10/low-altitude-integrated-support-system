# 无人机地面站系统

基于PyQt5和高德地图的无人机地面站控制系统，支持多无人机实时监控、遥测数据展示、天气信息获取、智能机位分配等功能。

## 📋 功能特性

### 🚁 无人机管理
- **多无人机同时监控**：支持同时连接和管理多架无人机
- **卡片堆叠容器**：采用堆叠卡片设计，支持左右箭头切换和列表快速跳转
- **实时遥测数据**：实时显示无人机的经纬度、高度、电量、卫星数等信息
- **动态添加/移除**：可随时添加新的无人机，移除不需要的无人机
- **自定义配置**：支持自定义无人机ID、名称、图标、串口号、波特率、机型
- **联动切换**：切换无人机卡片时自动切换到对应的飞手信息和机位卡片

### 📍 智能机位分配系统
- **机位管理**：支持室内/室外多种机位类型，每个机位有独立的优先级和特性
- **机位堆叠卡片**：采用卡片堆叠容器，支持左右箭头切换和列表快速跳转
- **自定义机位增删**：在”📍 机位管理”页可新增/删除自定义机位；自定义机位会持久化保存
- **天气智能分配**：基于实时天气数据，自动为无人机推荐最适合的机位
- **风险分析**：根据温度、风速、降水、能见度等多维度分析飞行风险
- **适合度评分**：每个机位根据天气条件和无人机特性计算适合度分数（0-100分）
- **机位状态可视化**：在机位管理面板中直观显示各机位的占用状态
- **一键智能分配**：自动为所有未分配的无人机分配最佳机位
- **手动分配/释放**：支持手动选择机位，也可随时释放已占用的机位
- **分配后卡片展示规则**：机位分配成功后，机位标签会显示在无人机标题后
- **联动显示**：切换无人机时自动显示该无人机已分配的机位，或显示第一个空闲机位

### 👨‍✈️ 飞手信息管理
- **飞手信息堆叠卡片**：采用卡片堆叠容器，支持左右箭头切换和列表快速跳转
- **卡片式集中管理**：每台无人机一张飞手信息卡片，显示飞手姓名、邮箱、电话
- **可编辑卡片**：双击输入框可编辑飞手信息，或点击”查看”按钮打开编辑弹窗
- **双向同步**：飞手信息修改后自动同步到主数据，供后续机位分配使用
- **联动切换**：切换无人机卡片时自动切换到对应的飞手信息卡片

### ✉️ 邮件通知（可选）
- **分配成功通知**：当为无人机分配机位后，如果对应飞手设置了邮箱且 SMTP 已启用，会自动发送“机位分配通知”邮件

### 🗺️ 地图功能
- **高德地图集成**：基于高德地图API，提供流畅的地图体验
- **实时位置显示**：无人机位置实时更新，带有自定义emoji标记
- **地面站标记**：显示地面站当前位置
- **卫星图层模式**：默认仅使用卫星图层（并叠加路网），不再切换普通地图
- **视野回跳**：支持通过地图左上角按钮快速回到当前地面站位置
- **轨迹记录**：自动记录无人机飞行轨迹（虚线显示）
- **连线显示**：地面站与无人机之间的实时连线
- **自动视野调整**：当无人机距离过远时自动调整地图视野

### 🌤️ 天气信息
- **实时天气**：根据地面站经纬度获取实时天气数据
- **详细气象信息**：温度、湿度、能见度、降水量、风速、风向、空气质量等
- **自动更新**：每5分钟自动更新一次天气数据
- **缓存机制**：网络异常时显示缓存数据

### 📊 用户界面
- **分屏设计**：左侧地图+日志，右侧无人机卡片+天气信息+机位管理
- **紧凑布局**：优化的UI设计，信息密度高
- **实时日志**：显示系统状态、连接信息、错误提示等
- **颜色标识**：电量、卫星数、机位状态等数据有颜色分级显示
- **机位信息集成**：无人机卡片直接显示分配的机位信息和释放按钮
- **快捷键**：`Esc` 支持全屏/退出全屏切换
- **统一字体与美化**：主要面板控件已统一风格与字体

## 🛠️ 技术栈

- **Python 3.7+**：主要编程语言
- **PyQt5**：GUI框架
- **PyQtWebEngine**：Web视图组件，用于显示地图
- **pymavlink**：MAVLink协议通信，用于无人机数据获取
- **aiohttp**：异步HTTP客户端，用于天气API调用
- **WeatherAPI.com**：天气数据提供商
- **高德地图API**：地图显示

## 🚀 快速开始

### 环境要求

- Windows 10/11（目前仅支持Windows位置服务）
- Python 3.7 或更高版本
- 有效的WeatherAPI密钥（免费）
- 有效的高德地图API密钥（已内置测试密钥）

### 安装步骤

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/yourusername/drone_ground_station.git
   cd drone_ground_station
   ```

2. **创建虚拟环境（推荐）**
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```

3. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

4. **配置API密钥**
   
   编辑 `config.py` 文件，替换以下内容：
   ```python
   # WeatherAPI密钥（替换为您自己的）
   WEATHER_API_KEY = "your_weatherapi_key_here"
   ```

   > **获取WeatherAPI密钥**：访问 [WeatherAPI.com](https://www.weatherapi.com/) 注册账号，在仪表盘获取免费API密钥（每月100万次调用）。

5. **运行程序**
   ```bash
   python main.py
   ```

### 首次运行

- 程序会自动获取您的位置（需要允许位置访问）
- 默认连接COM3端口的无人机（可在`config.py`中修改）
- 天气信息会自动获取并显示

## 📖 使用指南

### 无人机管理

#### 添加无人机
1. 点击右侧面板顶部的 **"➕ 添加无人机"** 按钮
2. 在弹出的对话框中填写：
   - **ID**：无人机唯一标识
   - **名称**：显示名称
   - **图标**：选择emoji图标
   - **机型**：选择无人机型号（影响抗风能力评估）
   - **串口**：如 COM3、COM5 等
   - **波特率**：通常为 57600 或 115200
3. 点击确定，无人机卡片会自动添加

#### 连接/断开无人机
- 点击无人机卡片上的 **"连接"** 按钮连接无人机
- 连接成功后按钮变为 **"断开"**，卡片边框变为绿色
- 注意：当无人机已分配机位后，“飞手/连接”操作行仍可正常使用（如需释放可在卡片内展开“释放机位”）

#### 移除无人机
- 点击无人机卡片右上角的 **"✕"** 按钮
- 确认删除后，卡片将被移除，相关线程停止，地图标记清除
- **自动释放机位**：如果该无人机已分配机位，会自动释放

### 飞手信息管理
1. 点击右侧面板的 **"👨‍✈️ 飞手信息"** 选项卡
2. 使用左右箭头或点击 **"📋 列表"** 按钮快速切换飞手卡片
3. 在飞手信息卡片中双击对应输入框可编辑飞手姓名/邮箱/电话
4. 也可以点击卡片里的 **"查看"** 打开弹窗进行确认编辑
5. 编辑完成后，后续机位分配将使用最新飞手信息（用于邮件通知/同步展示）
6. **自动联动**：切换无人机卡片时会自动切换到对应的飞手信息卡片

### 机位分配系统

#### 查看机位状态
- 切换到 **”📍 机位管理”** 选项卡
- 使用左右箭头或点击 **”📋 列表”** 按钮快速切换机位卡片
- 机位卡片（每个机位一张）：空闲/已占用状态标识，已占用时显示”释放机位”按钮
- 顶部显示统计信息：室内/室外机位占用情况
- **自动联动**：切换无人机卡片时会自动显示该无人机已分配的机位，或显示第一个空闲机位
> 说明：默认机位不可删除；正在被占用的机位不可删除。自定义机位保存在 `offline_data/stands_custom.json`。

#### 手动分配机位
1. 在无人机卡片上点击 **"📋 分配"** 按钮
2. 在弹出的对话框中查看当前天气分析和推荐
3. 从列表中选择合适的机位（可筛选室内/室外）
4. 查看每个机位的适合度评分（⭐推荐、✓可选、○一般）
5. 点击 **"分配机位"** 完成分配
6. 分配完成后，机位标签会显示在无人机标题后；若 SMTP 开启且飞手设置了邮箱，将自动发送机位分配邮件

#### 智能分配所有无人机
- 点击无人机面板顶部的 **"🤖 智能分配"** 按钮
- 系统根据实时天气自动为所有未分配的无人机分配最佳机位

#### 释放机位
- 在已分配机位的无人机卡片上，点击展开的 **"释放机位"** 按钮
- 确认后机位被释放，状态变更为空闲

### 查看遥测数据

每个无人机卡片显示：
- **纬度/经度**：当前位置（WGS84坐标系）
- **高度**：相对高度（米）
- **电量**：剩余电量百分比（颜色标识：绿>50%，黄20-50%，红<20%）
- **卫星**：GPS卫星数（颜色标识：绿≥6，黄<6）
- **机位信息**：如果已分配机位，显示机位标签和详细信息

### 天气信息

天气卡片显示：
- **天气状况**：如晴、多云、小雨等
- **温度**：摄氏度
- **湿度**：百分比
- **能见度**：公里
- **降水量**：毫米
- **风速**：公里/小时及风向
- **空气质量**：PM2.5及等级

### 地图操作

- **缩放**：鼠标滚轮或地图控件
- **平移**：鼠标拖拽
- **点击地面站标记**：显示地面站详细信息
- **无人机标记**：显示无人机图标和飞行轨迹

## ❓ 常见问题

### 无法获取位置
- 确保Windows位置服务已开启
- 检查应用是否有位置访问权限
- 可使用默认位置（北京）

### 无人机连接失败
- 检查串口号是否正确
- 确认波特率设置是否正确
- 验证飞控是否正常工作
- 查看日志中的具体错误信息

### 天气获取失败
- 检查API密钥是否正确
- 确认网络连接正常
- WeatherAPI免费版有每月100万次调用限制

### 机位分配无推荐
- 确保已获取到天气数据
- 检查机位配置是否正确
- 查看是否有空闲机位可用
