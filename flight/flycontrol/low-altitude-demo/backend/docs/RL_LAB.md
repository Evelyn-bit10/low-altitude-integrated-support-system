# RL 关联实验室（可视化）

> 把训练好的航迹关联策略做成一个**能玩**的页面：拖动 19 个特征滑杆，
> 实时看到 5505 个参数的神经网络怎么思考、输出什么概率、和规则差在哪。

打开方式：

- 执行工程根目录的 `低空系统.bat rl`（或双击 `低空系统.bat` 选 `[3]`，会自动检查后端）
- 或直接打开 `platform/portal/rl_lab.html`（需后端在 8080 运行）

---

## 1. 页面布局

```
┌──────────────┬──────────────────────────┬──────────────┐
│ 特征输入      │ 策略网络（Canvas 动画）   │ 判定结果      │
│ 19 个滑杆     │ 19 → 64 → 64 → 1         │ 概率环 + 阈值 │
│ 6 个预设场景  │ 节点亮度 = 激活值         │ 规则 vs 策略  │
│              │ 连线亮度 = 权重           │ 决策链文字    │
├──────────────┴──────────────┬───────────┴──────────────┤
│ 训练曲线（30 轮）            │ 规则 vs 策略 │ 模型在看什么 │
└─────────────────────────────┴─────────────┴────────────┘
```

## 2. 三个面板分别在讲什么

| 面板 | 内容 | 讲给谁看 |
| --- | --- | --- |
| **特征输入** | 一条候选边的 19 维特征，分组为 几何 / 身份 / 运动 / 源头 / 上下文 | "模型的输入是什么" |
| **策略网络** | 每一层节点的激活（亮=激活强）、连线的粗细（=权重）、前向传播动画 | "模型内部在算什么" |
| **判定结果** | P(同一架)、阈值的位置、接受/拒绝、规则基线打分、五步决策链 | "它怎么下结论" |
| **训练曲线** | 30 轮测试奖励 vs 规则基线（虚线） | "确实训好了" |
| **规则 vs 策略** | 奖励/误配/漏配/碎片数对比 | "好多少" |
| **模型在看什么** | 第一层权重范数（哪几个特征最重要） | "可解释性" |

## 3. 六个预设场景

| 按钮 | 场景 | 策略 | 规则 | 说明 |
| --- | --- | --- | --- | --- |
| 同一架（稀疏） | 距离近、方向一致、无 ID | 1.000 | 0.70 | 两边都判合并 |
| 交叉飞行 | 距离近但航向差 150° | 0.003 | 0.00 | 两边都拒绝（这是关键判据） |
| 蜂群密集 | 最近邻仅 10 m、40 条航迹 | 1.000 | 0.20 | 策略在密集场景更敢合 |
| ua_id 冲突 | 身份明确冲突 | （0.935 但被屏蔽） | 0.00 | **硬规则一票否决** |
| **分歧：策略多并** | 高差 47 m（超门限） | 0.928 | 0.00 | 影子模式要抓的样本 |
| **分歧：策略少并** | 低速目标、航向差 57° | 0.048 | 0.80 | 策略比规则保守 |

后两个是**故意放进来的分歧样本**——它们说明这个页面不只是"展示好看"，
而是真的能暴露出策略和规则不一致的地方，也就是影子模式（`docs/SHADOW.md`）
要抓的那两类情况。

## 4. 交互细节

- **滑杆实时推理**：全部在前端 JS 里跑（19→64→64→1 共 5505 个参数），零网络延迟；
- **动画**：节点激活带缓动，前向传播过程可见；
- **URL 参数**：`rl_lab.html?preset=extra` 直接进某个场景（方便截图/演示）；
- **阈值线**：圆环上的黄点、进度条上的黄线，都取 `/api/rl/model` 返回的 `threshold`（当前 0.80）；
- **规则基线**：用同一组特征按 `dedup.py` 的几何门限反算，与策略同屏对比。

## 4.1 实时影子流（边飞边看）

页面底部有一个**实时影子流**面板：把影子模式（`docs/SHADOW.md`）每帧的判定
拉过来滚动显示。

```
┌──────────────────────────────────────────────────────────────┐
│ 一致率 100.0% │ 一致 190 │ 策略多并 0 │ 策略少并 0 │ 阈值 0.80 │
├────┬───────┬───────┬────────────┬────────────┬──────┬───────┤
│ 帧 │ 来源  │ 本地ID│ 规则 →     │ 策略 →     │  p   │ 一致  │
│ 19 │ B-RID │ B-U7  │ G-UA-0007  │ G-UA-0007  │1.000 │  ✓    │
└────┴───────┴───────┴────────────┴────────────┴──────┴───────┘
```

**最有用的一点：点任意一行，把那一帧的 19 维特征灌进左侧模型**，
立刻在神经网络里看到"策略当时是怎么想的"——比看日志直观得多。

怎么让它有数据：

```powershell
# 1) 带影子模式启动
$env:DEDUP_SHADOW="1"
python -m uvicorn app.main:app --port 8080

# 2) 灌数据（另开一个窗口）
python tools/sim_two_devices.py --frames 60 --interval 0.5
```

页面每 1.5 秒拉一次 `/api/rl/live?n=40`。实现细节：

- 影子模块里有一个 400 条的环形缓冲（`ShadowMatcher.recent`），不读日志文件；
- 每条记录额外带 19 维 `feat`（该观测最高分候选边的特征），供"点行回放"；
- 未开启影子模式时面板显示提示，不影响其他功能。

## 5. 它背后的接口

```python
GET /api/rl/model
```

返回（只读，不参与业务）：

```json
{
  "features": ["距离/门限", "... 共 19 维"],
  "mean": [...], "std": [...],
  "weights": {"enc0_w": [19][64], "enc0_b": [64], "enc2_w": [64][64], ...},
  "threshold": 0.80,
  "expected":    {"reward": -959, "wrong": 753, "miss": 13, "frags": 2.10},
  "rule_baseline":{"reward": -1247, "wrong": 909, "miss": 38, "frags": 2.60},
  "history": [{"iter": 1, "test": -933.5, "wrong": 188}, ... 30 条],
  "model_info": {"layers": [19, 64, 64, 1], "params": 5505}
}
```

权重文件改动（重新训练）后接口会自动刷新（mtime 缓存），页面刷新即可看到新模型。

另有：

| 接口 | 用途 |
| --- | --- |
| `GET /api/rl/health` | 探活 |
| `GET /api/rl/live?n=40` | 影子模式最近 n 条判定（含特征） |

## 6. 演示建议

给不同观众用不同的预设：

- **给领导/客户**：点「同一架」看 1.000，再点「交叉飞行」看 0.003 —— 一句话讲清模型会区分；
- **给技术评审**：点两个「分歧」预设，说明这正是影子模式存在的理由；
- **给质疑"是不是写死"的人**：让他自己拖滑杆，看概率怎么变、网络节点怎么亮。

## 8. 排障

### 双击 bat 没反应

第一版 bat 用了 `^` 续行 + 中文 + PowerShell 长命令，cmd 会把续行后面的内容
当成独立命令，报"不是内部或外部命令"，窗口一闪就关。

**现在的写法**：纯 ASCII、不用续行、不用 PowerShell，只用 `curl.exe` 探活 + `start`。

如果双击仍然没反应：

```powershell
# 在 cmd 里手动跑，能看到报错
cd /d <工程根目录>
低空系统.bat rl
```

### 页面显示"未连接 8080"

后端没起来。手动启动：

```powershell
cd flight\flycontrol\low-altitude-demo\backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080
# 若已建好 .venv：.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8080
```

确认：`curl http://127.0.0.1:8080/api/rl/health` 应返回 `{"ok": true}`。

### 页面上概率一直是 —、滑杆不动

打开浏览器控制台（F12）看报错。常见原因：`/api/rl/model` 返回 404，
说明 `experiments/rl_dedup/policy_weights.json` 不存在（先跑
`python experiments/rl_dedup/run_all.py`）。

### 改了模型但页面没变

页面每次刷新都会重新拉 `/api/rl/model`（服务端 mtime 缓存会自动失效）。
若仍是旧数据，强制刷新（Ctrl+F5）。
