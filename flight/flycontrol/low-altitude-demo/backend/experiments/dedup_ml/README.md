# 去重关联：规则 vs 监督学习（可行性实验）

> 目的：验证"用学习的方法替代手工门限"是否值得。
> 结论先说：**在当前场景规则已经够好；差距出现在"目标间距接近观测噪声"时，学习同时降低误配和漏配，而调门限只能在两者间挪动。**

运行：

```powershell
cd flight\flycontrol\low-altitude-demo\backend
python experiments\dedup_ml\run.py      # 约 20 秒
```

## 1. 实验设置

| 项 | 设置 |
| --- | --- |
| 数据 | 自建仿真器 `sim.py`：12 架飞机、2 个观测源、1 Hz、逐帧带真值身份 |
| 观测源（常规） | A: σ=8 m、探测率 96%、带 ID 95%　B: σ=22 m、86%、55% |
| 观测源（困难） | A: σ=15 / 95% / 90%　B: σ=45 / 80% / 35%，且 B 有 +25/−15 m 系统偏差 |
| 观测源（极端） | A: σ=20　B: σ=60，12 架挤在 70×50 m 内 |
| 场景 | 稀疏 / 密集 / 交叉 / 编队（另加 困难·极端 变体） |
| 样本 | 每帧把「每条观测 × 每条候选航迹」展开成一对，标签=是否同一架 |
| 训练 | 4.7 万对（负样本 6:1 下采样）；验证集选阈值；测试集全量候选 |
| 模型 | 逻辑回归 / 随机森林 / 梯度提升（sklearn） |

**特征（16 维，全部是线上可得的量）**：距离/门限、绝对距离、高差、航向差、Δt、
ua/reg 相同·冲突·缺失、速度相对差、候选排名、航迹已跟踪帧数、源质量、源 σ、低速标志。

**对照基线**：
1. `规则(现状)` —— 与 `dedup.py` 完全一致的硬门限；
2. `规则(放宽)` —— 把门限放宽 50%（航向/高差 45°、距离 1.6 倍），用来检验"是不是调参就够了"。

## 3. 怎么读这组数

**① 规则的主要问题是"漏配"，不是"误配"**
常规场景漏配 5%（同一架被拆成两条 → 界面上出现重复目标），误配只有 0.5%。
原因是航向 30°、高差 30 m、门限 45 m 这些固定值卡得太死。

**② 单纯放宽门限只是在两者之间挪**
放宽后：常规 漏配 5.0%→2.3%，但误配 0.5%→0.7%；极端场景 误配 5.8%→7.4%。
因为门限是**一维**的：放松就等于"更容易认错"。

**③ 学习模型能同时降低两者**
因为它把距离、航向、高差、ID 状态**联合**起来判，而不是各自一刀切。
极端场景下误配 5.8% → 0.1~0.4%，漏配 6.6% → 0~0.6%。

**④ 距离仍然是最重要的特征**
前三名都是"距离类"，说明学习并没有推翻物理直觉，只是学会了更好的组合方式和阈值。

**⑤ 场景越难，学习收益越大**

| 场景 | 规则误配 | 学习误配 | 规则漏配 | 学习漏配 |
| --- | --- | --- | --- | --- |
| 常规 | 0.52% | ~0% | 5.0% | 0.1% |
| 困难 | 1.39% | ~0% | 5.9% | 0.14% |
| 极端 | 5.82% | 0.1–0.4% | 6.6% | 0–0.6% |

## 4. 必须说明的局限

1. **仿真太干净**：没有多径、没有 ID 伪造、没有目标急机动、源间时钟偏差只做了固定偏置。
   真实数据上模型不会这么完美，误差会明显上升。
2. **同分布测试**：训练集混合了三档场景，测试集也是同样三档，属于"见过同类"。
   跨机场/跨设备**没有验证泛化性**。
3. **误配 0 过于乐观**：真实部署一定会有误配，"零误配"不代表可以去掉安全规则。
4. **规则基线只有两种**：没有做门限网格搜索，放宽 50% 只是示意，不是最优手调。

---

## 5. 结论与建议

| 判断 | 结论 |
| --- | --- |
| 现在要不要上学习 | **不必**。12 架、2 源、间距 ≫ 噪声，规则 0.5% 误配已可接受 |
| 先做什么 | **把固定门限改成自适应**（按源 σ、按 Δt），能把漏配从 5% 降到 1~2%，成本最低 |
| 什么时候上学习 | 目标数 > 50、源 ≥ 3、或出现"间距接近噪声"的密集场景（编队/表演/城市峡谷） |
| 怎么上 | **影子模式**：模型与规则并行，只记录不生效，比对差异后再切换 |
| 红线 | `ua_id 冲突一票否决` 这类硬规则必须保留在模型之前，不可学习 |

---

## 6. 如果要做成生产

1. **数据**：用真实回放 + 仿真混合；重点是"困难样本"（密集、丢 ID、大偏置）。
2. **模型**：梯度提升（可解释、易部署）优先；逻辑回归可作为兜底与对照。
3. **部署**：模型输出 `P(同一架)`，配合 Hungarian 全局分配；阈值按"误配 ≤ 目标值"反解。
4. **监控**：上线后统计误配/漏配、模型分数分布漂移、特征缺失率。
5. **回退**：保留规则引擎作为 fallback，模型异常时自动切回。
